## 🚀 ¿Qué hace la página? (Funcionalidades)
El sitio web cumple con todos los requisitos del ejercicio de forma sencilla:

1. **Catálogo Dinámico:** Los paquetes de viajes no están grabados fijos en el HTML, sino que se cargan automáticamente desde JavaScript (usando un arreglo de objetos).
2. **Carrito de Compras Completo:** Puedes agregar viajes, verlos en la lista, eliminarlos y el sistema calcula el precio total automáticamente.
3. **Efecto Desplegable:** El carrito se abre de lado con una animación muy suave.
4. **Memoria (LocalStorage):** Si agregas viajes al carrito y recargas la página, tus compras siguen ahí guardadas.

## 🎨 Maquetación y Código
Para que sea un proyecto fácil de sustentar ante el profesor, aplicamos buenas prácticas:

* **Estructura limpia:** HTML5 semántico y ordenado. No hay estilos metidos a la fuerza dentro de las etiquetas HTML.
* **Flexbox y CSS Grid:** Usamos **CSS Grid** para acomodar las tarjetas de los viajes en la página principal y **Flexbox** para ordenar el menú y los botones.
* **Clases en Español:** Todos los nombres de los bloques y variables están en español y son muy intuitivos para que cualquiera entienda el código al primer vistazo.
